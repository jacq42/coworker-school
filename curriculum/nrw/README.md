# NRW Curriculum Integration

## 📋 **Lernpläne Upload-Bereich**

Dieser Ordner dient zum Upload der offiziellen NRW-Lehrpläne als PDF-Dateien.

### **Ordnerstruktur:**
```
curriculum/nrw/
├── lernplaene/
│   ├── deutsch-klasse-7.pdf
│   ├── englisch-klasse-7.pdf  
│   ├── latein-klasse-7.pdf
│   └── weitere-faecher/
└── README.md (diese Datei)
```

### **Upload-Richtlinien:**
- **Dateiformat**: PDF-Dateien
- **Naming**: `[fach]-klasse-[nummer].pdf`
- **Quelle**: Offizielle NRW Kernlehrpläne
- **Update**: Bei Lehrplanänderungen

### **Integration in Lernstruktur:**
Die hochgeladenen Lehrpläne werden referenziert in:
- Subject-spezifischen README-Dateien
- Lernziel-Definitionen  
- Assessment-Kriterien
- Progression-Mapping

### **AI-Agent Nutzung:**
- Automatische Extraktion von Lernzielen
- Abgleich zwischen Curriculum und Übungen
- Kompetenz-Mapping nach NRW-Standards
- Qualitätssicherung der generierten Inhalte
