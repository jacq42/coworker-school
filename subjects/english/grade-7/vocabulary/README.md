# Grade 7 English Vocabulary

## Learning Objectives
- Expand vocabulary to 1,500+ active words
- Master academic vocabulary for text comprehension
- Develop word formation strategies (prefixes, suffixes)
- Build thematic vocabulary clusters

## Weekly Vocabulary Sets
### Week 1: Academic Language
- analyze, evaluate, summarize, conclude, evidence
- **Prerequisites**: basic verbs from Grade 6
- **Assessment**: Use in 5-sentence paragraph

### Week 2: Descriptive Language
- vivid, eloquent, subtle, intricate, elaborate
- **Prerequisites**: basic adjectives
- **Assessment**: Character description task

## Vocabulary Learning Pathways
1. **Introduction**: Definition + pronunciation
2. **Context**: Example sentences + synonyms
3. **Practice**: Gap-fill exercises
4. **Application**: Creative writing tasks
5. **Assessment**: Quiz + peer teaching

## Progress Tracking
- [ ] Weekly vocabulary quizzes (80% mastery)
- [ ] Monthly cumulative assessment
- [ ] Semester portfolio review
