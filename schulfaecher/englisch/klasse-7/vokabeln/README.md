# Klasse 7 Englisch Vokabeln

## Lernziele
- Vokabular auf 1.500+ aktive Wörter erweitern (A2-Niveau)
- Akademisches Vokabular für Textverständnis beherrschen
- Wortbildungsstrategien entwickeln (Präfixe, Suffixe)
- Thematische Vokabel-Cluster aufbauen

## Wöchentliche Vokabel-Sets
### Woche 1: Akademische Sprache
- analyze, evaluate, summarize, conclude, evidence
- **Voraussetzungen**: Grundverben aus Klasse 6
- **Bewertung**: Verwendung in 5-Satz Absätzen

### Woche 2: Beschreibende Sprache
- vivid, eloquent, subtle, intricate, elaborate
- **Voraussetzungen**: Grundadjektive
- **Bewertung**: Charakterbeschreibungsaufgabe

## Vokabel-Lernpfade
1. **Einführung**: Definition + Aussprache
2. **Kontext**: Beispielsätze + Synonyme
3. **Übung**: Lückentext-Übungen
4. **Anwendung**: Kreative Schreibaufgaben
5. **Bewertung**: Quiz + Peer-Teaching
