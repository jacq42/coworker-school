# Coworker School

AI Agents Crew für Schulsachen - spezialisiert auf deutsches NRW Curriculum.

## 🎯 **Projektziele**

- ✅ Lernpläne aus verschiedenen Schulfächern erstellen
- ✅ Aufgaben basierend auf Lernplänen generieren  
- ✅ Grammatikübungen generieren (Deutsch)
- ✅ Leseverständnisübungen generieren
- ✅ Vokabelübungen für Fremdsprachen (Englisch, Latein)

## 📚 **Unterstützte Schulfächer**

### 🇩🇪 **Deutsch** (Muttersprache)
- **Schwerpunkt**: Rechtschreibung und Grammatik
- **Zielgruppe**: Deutschsprachige Schüler
- **Methodik**: Textanalyse-basierte Schwerpunkterkennung

### 🇬🇧 **Englisch** (1. Fremdsprache)
- **Niveau**: A2 nach CEFR
- **Schwerpunkt**: Kommunikative Kompetenzen
- **Zielwortschatz**: ~1000 aktive Vokabeln

### 🏛️ **Latein** (2. Fremdsprache)  
- **Lehrbuch**: Prima (Cornelsen)
- **Schwerpunkt**: Grundlagen lateinischer Sprache
- **Kulturkunde**: Römische Zivilisation

## 📋 **NRW Curriculum Konformität**

**Grundlage**: Nordrhein-Westfalen Kernlehrpläne für Gymnasium  
**Klassenstufe**: Schwerpunkt Klasse 7 (12-13 Jahre)  
**Standards**: Duden-konforme Rechtschreibung, CEFR A2, traditionelle Lateinpädagogik

## 🤖 **AI Agent Integration**

Dieses Projekt verwendet spezialisierte AI Agents für:
- **Spezifikation**: Erstellen detaillierter Lernziele
- **Planung**: Systematische Lernpfad-Entwicklung  
- **Aufgabengenerierung**: Curriculumskonforme Übungen
- **Bewertung**: Lernfortschritts-Tracking
- **Qualitätskontrolle**: Pädagogische Standards-Einhaltung

## 🎓 **Pädagogische Prinzipien**

1. **Educational Quality First**: Pädagogisch fundierte Inhalte
2. **Structured Learning Pathways**: Systematische Progression  
3. **Measurable Assessment**: Klare Bewertungskriterien
4. **Cultural Awareness**: Mehrsprachige und kulturelle Sensibilität
5. **Agent Collaboration**: Spezialisierte AI-Zusammenarbeit

## 🚀 **Erste Schritte**

1. **Lehrpläne hochladen**: PDF-Dateien in `curriculum/nrw/lernplaene/`
2. **Textanalyse**: Deutsche Schülertexte für Schwerpunkterkennung
3. **Lektionsdateien**: Spezifische Vokabeln/Grammatik hinzufügen
4. **AI Agents nutzen**: Automatische Übungs- und Aufgabengenerierung
